IT Support Diagnostic & Setup Toolkit

A hands-on toolkit for diagnosing, provisioning and networking a Windows machine, with a Linux health-check companion — built to be run by hand, not trusted blind. Browse the scripts and notes below, or read them straight from the repo.

7 parts — PowerShell scripts — Bash scripts — exercise notes Full README →

01 System diagnostic (Windows)

OS/edition/license, disk space, file system per drive, boot mode (UEFI vs Legacy), installed apps, network config, top 10 processes, then DISM/SFC/CHKDSK.

02 New employee onboarding (Windows)

Standard user creation, practice-disk partitioning, Windows Update pause, System Restore, theme via Settings vs registry, security verification.

03 Networking setup (Windows)

Static IP, firewall port blocking, network discovery, folder sharing, drive/printer mapping, RDP vs SSH vs remote tools, Workgroup vs Domain.

04 Linux health check (WSL)

Disk usage + largest files, tar.gz backups, hourly cron job, file organizing, permissions (chmod 750), user administration, networking commands, htop.

05 Application lifecycle (Windows)

Silent install/uninstall with a leftover check, minimum-spec comparison against Part 1's report, restricting an app's folder access.

06 Cloud productivity tools

Sync conflict resolution, view-only vs edit sharing, Storage-as-a-Service vs Software-as-a-Service — a fill-in observation exercise.
